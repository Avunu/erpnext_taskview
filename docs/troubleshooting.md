This page lists the known limits of TaskView for ERPNext, then the messages you can see while using it, grouped by where they appear. Messages are quoted as the code writes them; `…` stands for a name or a number the message fills in.

## Limitations

- Timers need **Ignore User Time Overlap** and **Ignore Employee Time Overlap** ticked in **Projects Settings**, and the app does not tick them for you. Since ERPNext 16.51.0 the user check applies to every Timesheet, so a site that worked on an older ERPNext can start refusing timers after an upgrade. See [Allow overlapping time logs](install.md#allow-overlapping-time-logs).
- A user who can only see a task cannot time it or log time on it. ERPNext's **Employee** role alone gives select on Task, not write. Give the person **Projects User**, or share the task with write access.
- A task can be renamed, re-statused, dragged or given subtasks in the tree only by a user who may write it, and for a drag also the new parent and every subtask that moves with it.
- Dragging works only while the list's sort is **Manual**.
- **Log time** records hours that end at the moment you submit. To log time on another day, edit the row's **From Time** in the draft Timesheet, or add the row in ERPNext with its **Project** and **Task**.
- The app adds no reports. Use the standard Timesheet list and report views.
- Customers on the portal cannot log time or run timers. They see the time logs only.
- Customers see every comment, file and time log description on the tasks of their projects, and the budget per phase. There is no setting to hide any of it. See [What customers can see](client-portal/administering-access.md#what-customers-can-see).
- On the portal, the four board columns (Open, Working, Pending Review, Completed), the file types customers may attach and the limit of 60 new tasks, 60 comments and 60 uploads per hour from one IP address are fixed in the code.
- Customers cannot paste images into comments or descriptions. They attach them as files.
- The portal ignores the **Hide timesheets** and **View attachments** options on a project's **Users** table.

## Troubleshooting

### Installing and opening the app

| What you see                                                  | Cause                                                                                                            | Fix                                                                                                                                                                       |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/projects` shows no portal, or a blank page                  | The app's assets were not built. The portal's page `www/projects.html` and its files are generated by the build. | Run `bench build --app erpnext_taskview` and check that `apps/erpnext_taskview/erpnext_taskview/www/projects.html` exists. See [Install and upgrade](install.md#install). |
| Task or Project opens as a plain list                         | The list was switched to **List**, or the bundles did not load.                                                  | Choose **Task View** in the view menu next to the title. If it is not offered, rebuild the assets and reload the page.                                                    |
| Customers land on a page that does not exist after signing in | **Default Portal Home** in **Portal Settings** still reads `/projects` after the app was uninstalled.            | Set another Default Portal Home. See [Uninstall](install.md#uninstall).                                                                                                   |

### Timers and logged time

| Message                                                                                                    | Cause                                                                                                                                                                     | Fix                                                                                              |
| ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| "Row …: From Time and To Time of … is overlapping with …"                                                  | ERPNext's overlap check. A paused timer's time log overlaps the timer that ran meanwhile.                                                                                 | Tick **Ignore User Time Overlap** and **Ignore Employee Time Overlap** in **Projects Settings**. |
| **Not permitted**, "No permission for Project" or "No permission for Task", sometimes followed by the name | You lack read on the task's project or write on the task. The name is added only when your roles give that permission on other documents of the type but not on this one. | Ask for **Projects User**, or for the task to be shared with write access.                       |
| **Not permitted**, "No permission for Timesheet …"                                                         | The draft Timesheet is not your Employee's and you did not create it, and your role cannot write it. This is the case when you stop or discard someone else's timer.      | Let the owner stop the timer, or get write permission on their Timesheet.                        |
| "Timesheet … is not a draft"                                                                               | The timer's Timesheet was submitted or cancelled.                                                                                                                         | Start a new timer: it goes to a new draft Timesheet.                                             |
| "Task … does not belong to Project …"                                                                      | The task was moved to another project, or you chose a task of another project in the **Log Timer** dialog.                                                                | Log the time on a task of the timer's project.                                                   |
| "Choose a task to log time on"                                                                             | The **Task** field of the **Log Timer** or **Log Time** dialog was cleared.                                                                                               | Choose a task of the timer's project and submit again.                                           |
| "Choose a project for this task before logging time"                                                       | The task has no project yet, which happens to tasks added with quick entry in **Pinned**.                                                                                 | Give the task a project. See [Give a task a project](task-view/README.md#give-a-task-a-project). |
| "Enter the hours to log." or "Enter the hours to log"                                                      | **Hrs** in the **Log Time** dialog is empty or zero.                                                                                                                      | Enter the hours, more than zero.                                                                 |
| "This task has … open subtask(s) and cannot be marked as Completed."                                       | You ticked **Completed** on a task whose subtasks are not all Completed. The time is logged; the task stays open.                                                         | Complete the subtasks first, then the task. A Cancelled subtask also blocks it.                  |
| "The time is logged, but the task could not be marked as Completed: …"                                     | ERPNext refused to complete the task, for example because a task it depends on is still open. The message ends with ERPNext's reason.                                     | Fix what ERPNext names, then complete the task.                                                  |

### The task tree and Pinned

| Message                                                                    | Cause                                                                                                                    | Fix                                                                                                                                                              |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| "Error updating data: …"                                                   | A change in the tree failed on the server. The rest of the message is the server's error. The tree reloads after it.     | Read the error: most often it is a permission or a validation message from ERPNext.                                                                              |
| "Copy to clipboard failed"                                                 | The browser refused every way of writing to the clipboard, or the task descriptions could not be loaded from the server. | Click the copy button again. If it keeps failing, open the site over HTTPS (browsers offer the clipboard only to secure pages) or allow clipboard access for it. |
| "Only a top-level task can be moved to another project here"               | The project chip in **Pinned** was used on a subtask.                                                                    | Move its top-level task, or drag the subtask in the tree.                                                                                                        |
| "Stop the running timers on this task before moving it to another project" | The task or one of its subtasks has an open timer, running or paused.                                                    | Stop or discard those timers in the dock, then choose the project.                                                                                               |
| "Choose a project for this task before unpinning it"                       | A task without a project would disappear from every view once unpinned.                                                  | Give it a project first.                                                                                                                                         |
| "Could not pin task …"                                                     | Assigning the task to you failed, so it could not be pinned.                                                             | Check that you can open the task, and try again.                                                                                                                 |

### The client portal

| Message                                                                                                                                             | Cause                                                                                                                     | Fix                                                                                                                                             |
| --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| "You do not have access to this project."                                                                                                           | The project does not exist, is Cancelled, or is not shared with this user. Both cases get the same message on purpose.    | Check the access rules. See [When a customer cannot see a project](client-portal/administering-access.md#when-a-customer-cannot-see-a-project). |
| "You do not have access to this file."                                                                                                              | The file is not attached to a task or project the user can open.                                                          | Attach the file to a task of the customer's project.                                                                                            |
| "This project is closed to new tasks."                                                                                                              | The project is Completed or Cancelled.                                                                                    | Reopen the project in the desk if the customer should add tasks.                                                                                |
| "Tasks can only be added under an open phase of this project."                                                                                      | The chosen phase is Completed or Cancelled, or is not a group task of this project.                                       | Pick an open phase, or no phase.                                                                                                                |
| "Please give the task a title."                                                                                                                     | The new task's title is empty.                                                                                            | Enter a title.                                                                                                                                  |
| "Please write a comment first."                                                                                                                     | The comment is empty, or held only content that is removed when it is cleaned, such as an image.                          | Write some text. Attach images as files.                                                                                                        |
| "Phases move with their tasks and can't be dragged."                                                                                                | A phase (a task with subtasks) was moved.                                                                                 | Move the tasks inside it instead.                                                                                                               |
| "Tasks can only be moved to Open, Working, Pending Review, Completed."                                                                              | A status other than the four board columns was sent.                                                                      | Use the board or the **Status** menu.                                                                                                           |
| "Cannot complete task … as its dependant task … are not completed / cancelled."                                                                     | The task depends on tasks that are still open.                                                                            | Complete or cancel those tasks first.                                                                                                           |
| "Files must be 25 MB or smaller."                                                                                                                   | The file is over the portal's limit, checked in the browser.                                                              | Make the file smaller, or share it another way.                                                                                                 |
| "You can only upload JPG, PNG, GIF, PDF, TXT or CSV files, Word, Excel or OpenDocument text and spreadsheet documents, or MP4 or QuickTime videos." | A customer chose a file of another type.                                                                                  | Convert the file to one of those types.                                                                                                         |
| "No file was uploaded."                                                                                                                             | The upload reached the server without a file.                                                                             | Choose the file again.                                                                                                                          |
| "You hit the rate limit because of too many requests. Please try after sometime."                                                                   | 60 new tasks, 60 comments or 60 uploads within an hour from one IP address. People on one office network share the count. | Wait, then try again.                                                                                                                           |

### Notifications

The team gets a **Client Portal** notification in the desk when a customer acts on the portal. If nobody is notified, check that the customer's user type is **Website User**: what a System User does on the portal notifies no one. If the notification arrives but no email does, check the recipient's **Notification Settings** and the site's outgoing **Email Account**. See [How the team is told](client-portal/README.md#how-the-team-is-told).
